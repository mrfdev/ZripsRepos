# TryMe

[![TryMe on SpigotMC](https://img.shields.io/badge/SpigotMC-TryMe-orange)](https://www.spigotmc.org/resources/3330/) [![GitHub issues](https://img.shields.io/github/issues/Zrips/TryMe)](https://github.com/Zrips/TryMe/issues) [![Zrips website](https://img.shields.io/badge/website-zrips.net-blue)](https://www.zrips.net/)

TryMe is a premium Minecraft server quiz plugin by Zrips. Players answer questions through chat to compete for configured rewards.

> [!NOTE]
> This repository is the official issue and feature-request tracker for TryMe. It does not contain the plugin source, downloads, or build files.

## Download and requirements

Get TryMe from its [official SpigotMC resource page](https://www.spigotmc.org/resources/3330/). A compatible version of [CMILib](https://www.spigotmc.org/resources/87610/) is required. Use the resource page for current compatibility and setup information.

## Issues and feature requests

Search the [existing issues](https://github.com/Zrips/TryMe/issues) before opening a new one. Please include:

- TryMe, CMILib, Minecraft, and server-software versions;
- reproduction steps and the expected and actual behavior; and
- relevant errors, logs, and related plugin versions.

Prefix feature-request titles with `[Feature Request]`. For payment, licensing, or another private matter, [PM Zrips on SpigotMC](https://www.spigotmc.org/conversations/add?to=Zrips). Community help is available on the [Zrips Discord](https://discord.gg/dDMamN4). Contact Zrips privately before publishing details of a possible exploit or another security-sensitive problem.
